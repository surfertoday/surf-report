# SurferToday Global Wave & Wind Map

An interactive global map of ocean wave and wind observations.

## Data sources

- NOAA National Data Buoy Center (NDBC)
- European ocean observation networks
- International coastal meteorological stations

## Measurements

- Significant wave height
- Dominant and average wave period
- Wave direction
- Wind speed and direction
- Wind gusts
- Sea surface temperature

## Technology

- Leaflet
- JavaScript
- HTML and CSS
- GitHub Pages

Maintained by SurferToday.com.
